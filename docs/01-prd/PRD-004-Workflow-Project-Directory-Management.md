> **文档版本**: 1.0.0  
> **状态**: 已实现 (Implemented)  
> **最后更新**: 2026-09-02  

---

## 1. 需求背景与目标

在复杂的多 Agent 与长链 Prompt 编排场景中，用户通常会创建多个针对不同业务（如客服路由、研报生成、代码审核、数据清洗）的工作流。为了避免单画布混乱，提升工作流的管理与复用效率，系统需提供类似于 **Google Antigravity** 的现代化左侧抽屉式侧边栏。

### 核心目标：
1. **多工作流隔离与快速切换**：支持随时新建空白工作流，并在不同工作流之间无缝切换。
2. **分层目录与分类归档**：支持新建自定义目录、重命名、删除、折叠/展开，并支持工作流跨目录移动。
3. **流畅的交互体验**：支持双击行内重命名、相对时间标识（如 `10m`、`2h`、`1d`）、工作流副本复制与删除保护。
4. **完全本地持久化与内置预设**：首期支持基于 LocalStorage 的数据持久化，并预置官方工业级模板库。

## 2. 功能清单与规格说明

### 2.1 侧边栏布局与顶部操作
- **`+ New Workflow` (新建流程)**：顶部主操作药丸按钮，点击后立即清空当前画布并载入基础脚手架节点（Input ➔ LLM ➔ Output）。
- **`🕒 Workflow History` (流程历史)**：快速重置过滤条件，展示全部工作流列表。
- **即时搜索与过滤 (Realtime Search)**：支持根据流程名称对全部工作流进行不区分大小写的关键词模糊过滤。

### 2.2 目录与项目分类管理 (Projects & Folders)
- **新建目录**：点击目录标题栏右侧的 `+` 图标，展开行内输入框，输入目录名后回车确认。
- **目录折叠/展开**：点击目录名称所在行即可切换子流程列表的显示状态，并记录展开状态。
- **目录重命名与删除**：悬停时提供编辑与删除图标；删除目录时，其内部工作流将自动移入默认目录以防数据丢失。
- **预设目录保护**：官方预设库目录（如 `Official Presets`）禁止直接删除。

### 2.3 工作流项操作与上下文菜单
- **激活高亮**：当前正在画布中编辑的工作流，在列表中以圆角高亮背景呈现。
- **行内双击重命名**：双击流程名称直接变为输入框，支持 `Enter` 保存、`Esc` 撤销。
- **右侧选项菜单 (`...`)**：
  1. `Rename`：重命名流程。
  2. `Duplicate`：创建副本（自动追加 `(Copy)` 后缀）。
  3. `Move to Folder`：二级联动子菜单，选择目标目录实现跨目录归类。
  4. `Delete`：删除当前工作流（附带确认对话框）。

## 3. 技术实现架构与数据流

### 3.1 状态管理 (`src/stores/project-store.ts`)
- 基于 **Zustand + Immer** 建立独立的工程目录状态：
  - `folders: Folder[]`
  - `workflows: SavedWorkflow[]`
  - `activeWorkflowId: string | null`
  - `isSidebarOpen: boolean`
  - `searchQuery: string`
- 自动同步至 `useWorkflowStore`，当用户切换工作流时，调用 `loadPreset()` 动态刷新画布节点与连线。

### 3.2 持久化 Key 规范
- 目录结构：`patchcat_folders_v2`
- 工作流数据：`patchcat_workflows_v2`
- 激活项标识：`patchcat_active_workflow_v2`
- 侧边栏折叠：`patchcat_sidebar_open_v2`
