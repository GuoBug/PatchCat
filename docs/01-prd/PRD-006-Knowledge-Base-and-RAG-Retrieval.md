> **文档版本**: 1.0.0  
> **所属阶段**: 第二阶段（Phase 2）  
> **状态**: 实施中 (In Progress)  
> **最后更新**: 2026-09-03  

---

## 1. 产品背景与目标

在复杂 AI 工作流编排中，LLM 仅凭预训练权重无法掌握用户的私有数据、企业文档或最新行业资料，容易产生幻觉。通过引入 **知识库（RAG）系统**，用户可以在 PatchCat 中上传私有文档、自动切片建立向量索引，并在画布中直接拖出【知识库检索节点】，实现精准的上下文增强生成。

---

## 2. 功能清单与规格说明

### 2.1 知识库管理（Knowledge Base Management）
- **知识库 CRUD**：支持创建多个针对不同业务领域（如产品文档、内部规范、技术 FAQ）的独立知识库。
- **Embedding 模型配置**：
  - 支持绑定 OpenAI (`text-embedding-3-small`)、硅基流动 (BGE) 或 本地 Ollama 模型；
  - 记录模型维度（1536, 1024, 768）以确保向量一致性。

### 2.2 文档与分块管理（Documents & Chunks）
- **文档导入**：支持上传 `.txt`, `.md`, `.pdf` 格式文本；
- **分块规则配置**：
  - Delimiter（分隔符，如 `\n\n`）；
  - Maximum chunk length（单分块最大字符数，默认 500）；
  - Chunk overlap（分块重叠字符数，默认 50）；
- **切片状态机**：文档解析经历 `queuing ➔ indexing ➔ completed / error` 状态流转。

### 2.3 画布检索节点（Canvas Knowledge Retrieval Node）
- **节点输入**：`query`（查询语句，可引用输入节点或上游大模型输出）；
- **节点属性配置**：
  - 选择关联的知识库（单选/多选）；
  - `Top-K`（返回相似度最高的前 K 条切片，默认 3）；
  - `Score Threshold`（最低相似度过滤阈值，如 0.5）；
- **节点输出**：
  - `result`：拼接好的完整上下文 Markdown 字符串（直接供 Prompt 模板使用）；
  - `chunks`：结构化切片数组（包含原文档名、相似度分数、切片内容，供前端展示引文卡片）。

---

## 3. 验收标准
1. 后端支持创建知识库、添加文档、切片向量化与 Top-K 向量检索；
2. 本地模式下免 Docker 无报错运行（基于 SQLite JSON 向量计算）；
3. 前端画布可通过【知识库节点】成功召回匹配切片并输入给 LLM 节点生成准确回答。
